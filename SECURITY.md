# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[open a private report](https://github.com/rohal12/spindle/security/advisories/new)
(the **Report a vulnerability** button on the repository's Security tab). Do
not open a public issue for a vulnerability.

A useful report says what an attacker can do, the Spindle version, and how to
reproduce it: a story or passage, a script, or steps. You will get an answer in
the report, which stays private until a fix is released and the advisory is
published.

## Supported versions

Spindle is in beta (0.x). Fixes are released only as new versions of the
[`@rohal12/spindle`](https://www.npmjs.com/package/@rohal12/spindle) package
and of the story format built from it, so please check that a problem is still
present in the latest release.
