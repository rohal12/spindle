# Review issues #583–#588 implementation plan

**Goal:** Resolve the six reproduced review findings with regression coverage.

**Architecture:** Keep fixes at their shared runtime boundaries. Require explicit
trust before Node story execution; validate metadata without dense copies; share
indexed source line lookups across formatter consumers. Preserve existing runtime
and formatter contracts for valid content.

**Spec:** GitHub issues #583, #584, #585, #586, #587 and #588.

**Constraints:** Follow bundle AGENTS.md; TypeScript with two-space indentation;
update public declarations, documentation and changelog for behavior changes.

## Tasks

1. Play sessions (`src/play/session.ts`, `types/play.d.ts`, play tests,
   `docs/automation.md`): test refusal without explicit trust, then require
   `trusted: true` before creating a worker. Retain existing trusted-session tests.
2. Save metadata (`src/saves/format.ts`, save-format tests): test compact sparse
   history and watchers under an allocation guard; validate each entry without
   expanding the logical length, stopping at the first hole or invalid entry.
3. Formatting (`src/format/markdown-lines.ts`, `format-passage.ts`, new line index):
   test output and bounded scan work over many constructs; index source lines and
   binary-search overlapping spans rather than revisiting prefixes and all spans.
4. Raw bodies (`src/format/placeholders.ts`, `markdown-lines.ts`, do-literal tests):
   test uppercase and mixed-case template literals and wrapping, then normalize
   macro names when recognizing raw JavaScript bodies.
5. Automation (`src/automation/runner.ts`, headless and package regressions): test
   missing/special starts and valid redirects; observe navigation acceptance on
   the supplied runtime so separate package bundles work, and fail before
   executing steps when the requested start cannot be navigated to.
6. Bindings (`src/define-macro.ts`, binding tests): test escaped root/member names
   and quoted forms; decode JavaScript identifier escapes before building paths,
   including the reserved-name check.

For each task: run the new regression before implementation, verify the intended
failure, implement, then rerun the focused suite. Review the combined diff and run
the full tests, typecheck, build, formatting checks and browser regressions. Commit,
push, recheck for an existing PR and create or update the PR with issue links and
validation results.

## Review focus

- Untrusted calls must fail before any worker or story code runs.
- Sparse metadata must reject holes while valid dense saves still round-trip.
- Offset lookup must preserve newline boundaries and nested Markdown documents.
- Valid automation redirects must remain successful.
- Escaped identifiers must still enforce reserved-name and namespace rules.
